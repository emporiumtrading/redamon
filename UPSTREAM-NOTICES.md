# Upstream notices and retained compatibility names

Gabriel is developed in a repository derived from [RedAmon](https://github.com/samugit83/redamon). Upstream copyright notices, the MIT license and third-party licensing records remain unchanged. These notices acknowledge provenance; they do not describe Gabriel as the original product or claim upstream endorsement.

The original operational disclaimer is retained verbatim at [docs/upstream/DISCLAIMER.md](docs/upstream/DISCLAIMER.md) for the inherited source. Historical source paths, test-runner variables, audit records, evidence links and Git commit history may retain upstream names. Existing public GitHub URLs remain valid until an actual repository rename occurs.

The Gabriel runtime is built from the explicit defensive image and compositions. The retained `agentic/`, `recon/`, `scanners/`, `mcp/`, `webapp/` and original deployment tooling are inherited source, not the Gabriel analyst UI or supported Gabriel installation path. Rebranding those offensive workflows as defensive capabilities would misrepresent the product; the runtime tests verify their exclusion.

Gabriel's own visual identity is the halo and winged shield in [docs/assets/gabriel](docs/assets/gabriel/), matching the workbench. The old upstream logo, screenshots and media are not used in Gabriel's repository landing page or analyst interface. Their preservation in source history does not make them Gabriel brand assets.
