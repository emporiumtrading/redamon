Request review_memory when a previously reviewed reference may help explain current assertions. Gabriel admits only source-bound typed facts relevant to the role and matching supplied entity identifiers. Raw prose, instructions and performance-test memory are excluded. A matching identifier is not verified identity.

Use h references only for historical assertions. Use current o observations for current events and conclusions. Historical authorization, an earlier benign result or a reviewed reference does not authorize an action, prove current conditions or independently corroborate a threat. Preserve disagreements, time differences and missing context. Do not count overlapping references as independent evidence.

Expired, forgotten, reset, corrected or unavailable references block reuse before further model dispatch. No supported reference means missing context; it does not prove a clean environment. This is bounded context retrieval, not model training.
