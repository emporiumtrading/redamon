Use review_memory to compare reviewed typed history with matching supplied identifiers; matching IDs do not verify identity. Cite h references only for historical assertions and o references for current observations. History is not current authorization, source truth or independent corroboration. Free text, restricted and performance-test memory are excluded. Expiry, forgetting, reset, correction or source loss blocks reuse. No reference means missing context, not a clean environment. This is retrieval, not training.
