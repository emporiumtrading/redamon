# Gabriel visual design

Gabriel's angelic namesake informs a restrained visual language: a halo over a winged shield, midnight blue surfaces, warm gold accents and pearl text. The emblem is a decorative inline vector; its accessible brand name is Gabriel — The Defender. Light, protective shapes and quiet orbital lines provide identity without interrupting evidence review.

The shared workbench template styles every existing screen, including authentication and access errors. It provides role-scoped navigation, page descriptions, clear forms, section cards, local table scrolling and a mobile layout. Case tools are visually grouped while retaining their existing links. The browser companion follows the same palette and groups its existing controls into source selection, connection, assigned tours and reviewed sharing. Stop remains sticky and distinct.

All content remains server-rendered. There are no third-party fonts, images, requests, scripts or new runtime dependencies. CSS remains protected by the existing exact content-security-policy hash. Case state, evidence limits, unknowns, costs and role checks retain their existing meanings; decorative treatment makes no claim of monitoring coverage or a verified security outcome.

Keyboard focus, skip navigation, labeled scrollable tables, forced-color styles and print styles are included. The eight-screen browser visual check records generated-only desktop and mobile screenshots and checks page and form-control bounds in Chrome and Brave alongside existing functional journeys. These checks do not establish full accessibility conformance or native macOS acceptance; human UAT remains required.
