# Gabriel graphics

These assets use the same angel-inspired halo and winged shield as the Gabriel analyst workbench: midnight blue, warm gold and pearl text.

- `mark.svg`: scalable emblem.
- `banner.svg`: repository landing-page banner.
- `social-preview.svg`: editable 1280 × 640 social-preview artwork.
- `social-preview.png`: rendered image for repository social-preview upload.

The PNG is rendered from the vector artwork. The banner and preview use locally available system/serif fonts and contain no external asset requests. These are Gabriel graphics; upstream logos and screenshots are not used for the active product identity. License and provenance notices are maintained at the repository root.
